## 📖 Descripción del Proyecto

Esta aplicación web interactiva permite explorar visual y conceptualmente los dos enfoques analíticos basados en tríadas más estudiados en la ciencia y la informática moderna:

1. **La Tríada Epidemiológica (Ciencias de la Salud):** Analiza el proceso de causalidad y propagación de patologías infecciosas a través del equilibrio entre agente etiológico, huésped susceptible y medio ambiente.
2. **La Tríada CIA (Ciberseguridad y Sistemas):** Representa los tres pilares esenciales para la gestión de la seguridad de la información: Confidencialidad, Integridad y Disponibilidad.

El sistema incorpora un diagrama triangular interactivo, fichas técnicas por elemento, ejemplos prácticos reales y un generador en tiempo real de reportes en formato Markdown (`.md`).

## 🔺 Resumen de Contenidos

### 1. Tríada Epidemiológica
* **Agente Causal:** Factor biológico, físico o químico indispensable para el desarrollo de la enfermedad (virulencia, infectividad, patogenicidad).
* **Huésped Susceptible:** Organismo vivo que alberga el agente (inmunidad, genética, edad y factores de riesgo).
* **Medio Ambiente:** Entorno físico, biológico y sociocultural que facilita el contacto entre el agente y el hospedador.

### 2. Tríada de Ciberseguridad (CIA)
* **Confidencialidad:** Garantiza que los datos solo sean accesibles para usuarios y procesos autorizados (cifrado AES/TLS, RBAC, MFA).
* **Integridad:** Asegura la veracidad, completitud y exactitud de los datos evitando alteraciones ilícitas (hashing SHA-256, firmas digitales).
* **Disponibilidad:** Asegura el acceso ininterrumpido a sistemas y servicios en el momento requerido (redundancia, alta disponibilidad, mitigación de DDoS).

## 🚀 Puesta en Marcha Local

Si deseas ejecutar o editar el proyecto en tu entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/hackerobandoler01010110/infograf_triada.git
   cd infograf_triada
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
